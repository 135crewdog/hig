# HIG repository

The user's design philosophy for simple apps, published at https://135crewdog.github.io/hig/ by `pages.yml`.

- `index.html` is the philosophy; there is no other copy. Three pillars (Simple, Future-proof, Efficient), then the Baseline, each with one short real example from Show Time or Apollo.
- The words are the user's. Keep them as agreed; propose any change in wording and wait for agreement before writing it.
- Stay out of the weeds: no technical rules, code or CSS values on the page. Detail belongs to Apple's HIG and to each app's own code and CLAUDE.md.
- A pull request waits for the user's review; never merge one unasked.
