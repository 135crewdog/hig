# HIG

A design philosophy for simple apps: three pillars (Simple, Future-proof, Efficient) and a baseline every app starts from. Read it at https://135crewdog.github.io/hig/.

`index.html` is the whole thing; there is no other copy. Apple's [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) cover the detail, and [Show Time](https://github.com/135crewdog/showtime) and [Apollo](https://github.com/135crewdog/apollo) are the working examples.

`media/` holds the two screen recordings used under "Know who it's for", clipped from iPhone recordings. `pages.yml` publishes the page on every push to main.
