# HIG

Personal Human Interface Guidelines for small, simple, future-proof Progressive Web Apps. They are built on [Apple's HIG](https://developer.apple.com/design/human-interface-guidelines/) and drawn from two working apps, [Show Time](https://github.com/135crewdog/showtime) and [Apollo](https://github.com/135crewdog/apollo).

- **[HIG.md](HIG.md)**: the guidelines.
- **[starter/](starter/)**: a blank app that already follows them. A new project starts by copying it.

A project adopts the HIG with one line at the top of its `CLAUDE.md`:

> Follows the HIG at https://github.com/135crewdog/hig.
